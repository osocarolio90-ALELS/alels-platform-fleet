Type BLE mengikuti registrasi dan identitas terverifikasi, bukan AVL ID. Transport aplikasi, codec, capture mode dan advertising protocol dipisahkan. ALELS JSON tidak membuktikan codec asal. Banyak IO hanya digabung jika ada slot-to-MAC terverifikasi dan berasal dari packet/timestamp yang sama; RSSI tidak dibawa dari packet lama.

Firmware EYE 01.02.10+ pada BTSMP1/BTSID1 adalah perubahan konfigurasi sensor/protocol perangkat EYE, bukan versi firmware FMC650. [FMC650 PCN](https://wiki.teltonika-gps.com/view/FMC650_Product_Change_Notifications) bukan bukti versi receiver terpasang. Tidak ada upgrade firmware dalam tugas ini.

Rencana aman: penambahan hanya parser BLE existing + pemetaan baca/API/card. Jalur general parser, normalizer ingestion, ACK, routing, migrasi, registry dan persistence tidak diubah. Representasi baru tetap tersimpan di raw telemetry yang sudah ada; normalized BLE history khusus untuk representasi baru memerlukan review terpisah bila kontraknya tidak mencukupi. Matriks ini dicatat sebelum implementasi; hasil tes dan readiness aktual akan dilaporkan terpisah.
